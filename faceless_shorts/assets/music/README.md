# Background music (optional)

Drop royalty-free `.mp3` / `.wav` tracks here. One is picked at random per video,
looped, and ducked under the voiceover (volume set by `background.music_volume`
in `config.yaml`). Empty folder = no music.

**Free, royalty-free sources:**
- https://pixabay.com/music/  (no attribution required)
- https://incompetech.com/music/royalty-free/  (attribution required)
- YouTube Audio Library (in YouTube Studio) — safest for monetisation.

⚠️ Only use music you have the right to use, or your videos may be claimed/muted.
