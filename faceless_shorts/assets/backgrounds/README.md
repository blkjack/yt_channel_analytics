# Background videos (optional)

Drop vertical (or any) looping `.mp4` / `.mov` / `.webm` clips here and the
pipeline will pick one at random and crop it to 1080x1920.

If this folder is empty, the pipeline generates an animated gradient instead —
so backgrounds are completely optional.

**Free, royalty-free sources** (download a few calm/cinematic loops):
- https://www.pexels.com/videos/  (search "abstract", "nature", "particles")
- https://pixabay.com/videos/
- https://mixkit.co/free-stock-video/

Keep clips short (10–30s) — they loop automatically.
